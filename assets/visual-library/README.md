# Source visual library

This directory holds the **source masters** for Agency Bloom's visual library. It is outside `apps/miniprogram`, so none of these files ship in the Mini Program package.

## Layout

```text
originals/
  direction/    7 forest-path, meadow-path, and lake-canoe masters
  reflection/  11 reading-desk, window, seat, lakeside masters
  growth/       2 lavender-lake and bluebell-forest masters
  rest/         7 lake, moon, forest, and night-reading masters
references/
  reference_bloom_pages_pair_01.png   design reference only
recipes/
  bloom-pages.json                    legacy theme crop recipe
  visual-cards.json                   new card-derivative recipe
```

Every original is tracked by `docs/image-asset-audit.csv` and `assets/visual-manifest.json`. The manifest records its stable ID, category, description, tags, page/role suitability, theme compatibility, original path, SHA-256, byte size, dimensions, status, and runtime variants.

## Ownership and provenance

All photographic sources were generated by the project owner with ChatGPT; the owner confirmed deployment rights. The one user-supplied design reference is marked `source: user-supplied-design-reference`, kept for documentation, and excluded from the candidate pool. Do not present the reference screenshot as content imagery.

## Stable IDs

- IDs are lowercase snake_case and do not depend on the original opaque filename.
- Category-prefixed filenames are for human scanning only; the ID remains stable if a file is moved between folders.
- IDs never change when a theme changes or when a runtime derivative is regenerated.

## Source rules

- Preserve every original and its original extension. `.jfif` sources stay `.jfif`; do not re-encode just to rename.
- Do not overwrite an original with a crop, resize, or theme derivative.
- Runtime JPEGs live under `apps/miniprogram/src/static/`; source masters live here.
- Archived sources remain in place with `status: archived` and `deploy: false`. They have no runtime variants.
- Reference-only sources remain in `references/` with `status: reference-only` and are not selectable.
- The six frozen files in `design/themes/references/` are not part of this directory and must not be modified.

## Adding or changing an image

1. Add the source to the appropriate `originals/` category without renaming or re-encoding it.
2. Add its manifest entry with a new stable ID, source SHA-256, byte size, dimensions, source group, and honest page/role/theme suitability.
3. Generate the runtime derivative only if the image is deployed. New cards use the 224x360 recipe in `recipes/visual-cards.json`.
4. Update `docs/image-asset-audit.csv` and `docs/image-asset-migration-map.md`.
5. Run `npm run check:visuals` and the visual tests.
6. Regenerate the contact sheets with `npm run visuals:sheets`.

Never invent a dark variant. If a real night source does not exist, leave the slot text-only rather than relabeling daylight imagery.

See [`docs/VISUAL-ASSET-SYSTEM.md`](../../docs/VISUAL-ASSET-SYSTEM.md) for the full contract.
