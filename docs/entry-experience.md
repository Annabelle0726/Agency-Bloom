# 首次体验与登录入口

## 进入规则
- 启动时先判断本机 session；有 session 时先恢复账号，不闪现开场。
- 未登录且尚未看过开场：五幕开场。已看过开场：登录页，可主动重看。
- 开场前四幕点击画面前进，圆点可返回。最后一幕保留唯一主按钮「开始我的探索」，进入登录页。顶部「直接登录」同样进入登录页。
- 微信统一登录／注册；服务端识别账号，不增加密码或资料填写页。
- 登录后有当前探索：直接恢复首页。只有历史探索的账号也进入首页。
- 没有探索的新账号进入轻量问题。可随时「稍后再说」，先进入空首页；之后主动继续。
- 点击「保存这次探索」才创建记录。登录、跳过、恢复会话都不创建空探索。
- 原 FirstArrival 宣言页不再接入入口；宣言收进开场第五幕。

## 问题和草稿
- 第一问：最近有什么让你感到焦虑、害怕或不安，也保留好奇／不确定选项。
- 所有文字输入均为选填且默认收起；方向、具体线索、生活背景、支持方式优先点选。
- 草稿在设备上保留 7 天，按账号分别存储；保存成功后清理对应草稿。
- 旧匿名草稿只在用户主动选择「恢复本机草稿」后迁入当前账号；旧登录页／游客页步骤恢复到最终确认页。
- AI 对话仍需要单独同意。

## 视觉
- 第一幕使用新生成的「背影坐在山前、远望晨光」背景 opening-mountain-person.jpg。
- 参考引导生成，提示词保存在 opening-image-prompts.json。仅进行了等比例缩放和 JPEG 编码。
- 标题使用系统楷体优先、宋体兜底；正文使用衬线字体，重点文字按场景着色。
- 标题、短正文、右下短句分布在画面不同位置。逐行淡入，重看不重复播放已读幕的动画；支持减少动态效果。
- 其他四幕继续使用水面、休息、路径、草地意象。
- 小屏幕正文可滚动，底部导航／最后按钮固定，滚动不触发翻页。

## 本机演示登录与问答视觉（2026-10-18）
- 修复原开发登录接口每次创建新账号的问题。没有本机凭据时显示「创建演示账号」；有凭据时显示「继续本机演示」，恢复同一账号及其探索。
- 演示恢复凭据由服务器随机生成，本机保留，服务器只存带独立命名空间的摘要，30 天到期。它不能直接作为业务 API 会话使用；注销当前会话后仍可主动登录，删除账号会使凭据失效。
- 新建另一个演示账号需要确认更换本机入口；网络失败不清除旧凭据。过期／删除后的恢复请求明确失败，不自动注册。
- 旧版本仍保持登录的演示账号，在退出时可用当前有效会话建立恢复凭据；已经退出且没有保留凭据的旧账号不能仅凭账号 ID 找回。
- 所有演示身份接口仅在 development 且 allow_dev_auth 开启时提供；微信身份流程仍按微信授权识别。
- 问答五页分别使用水面、路径、休息、草地、晨曦背景。主选项为场景缩略图、图标徽章和文字组合，生活背景为双列图标卡片，选中后改变背景、边框并显示勾选。
- 延续原有多选／单选规则与可跳过设计，文字输入保持选填并默认收起。素材复用现有开场图片，没有增加网络图片依赖。

本轮验证：后端 16 项（含 9 项新增开发登录测试）、前端 21 项通过；类型检查与 Ruff 检查通过。模拟器验证了创建账号、选择状态、暂停／续填、保存、退出后继续同一演示账号，无异常；测试前本机存储已恢复。


## 语义插画与生活气泡（2026-10-18）
- 主选项改用本地 SVG 语义插画：指南针对应方向、芯片对应 AI 变化、分岔路对应选择、护盾与钱币对应安全感；支持方式同样使用对应插画。风景仍保留为页面背景。
- 生活背景改为 11 个可多选气泡，SVG 和文字放在圆内。大小不一、错落聚拢、边缘轻微交叠；尺寸仅用于构图，不代表优先级。
- 气泡位置稳定，点击轻弹、变色并打勾，再次点击取消。选中后提升层级；支持减少动态效果。保留原选项、草稿恢复、跳过和默认折叠的选填输入。
- 小屏幕按容器宽度缩放气泡，内容区域可滚动，底部继续按钮固定。

验证：类型检查、生产构建、开发／生产微信编译器检查通过；430 × 932 微信模拟器完整入口流程通过，无运行异常。检查了 11 个气泡的圆形比例、明显的尺寸差异、多选、取消、草稿恢复，以及滚动后所有气泡均能露出底部按钮区域。已检查首问插画、气泡默认／选中／滚动到底的截图；所有请求模拟，结束恢复原存储。
