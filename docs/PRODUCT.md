# 第一版产品约定

我们不断向前，是想靠近怎样的生活

帮助用户靠近自己愿意亲自度过的生活，保留行动、休息、求助与修改目标的选择权。当前仍从工作与方向中的具体问题切入，不把努力直接解释为内耗，也不把收入、效率或坚持默认当成唯一标准。方向分支关注期望的日常生活；反馈可记录事实、感受与改变，不要求每次都有进展。复盘一次只追问一个有用的问题，不增加打卡或绩效评分。

面向成年人，帮助人理解处境、面对不确定性、理清重要的事，并在现实中迈出一步。它不是传统任务规划器、通用聊天壳、心理诊断或治疗产品，也不以情感依赖为目标。首批本地试用者为作者和 1–2 位朋友。

2026-10-17 的探索版本聚焦职业探索：方向、已有经历的新用途、选择比较、可控改变和未曾想到的可能。保留用户提供的八屏设计图的视觉语言，技术沿用 Vue 3 + TypeScript + uni-app。旧账户与卡片仍保持原值，不因入口更新而重新分类

流程为可跳过的五页思考开场、探索意图多选、选定主线并回答分支问题、可跳过的生活背景、帮助方式、固定问题初步整理、登录保存、首次理念页、首页。理念页只在保存成功后展示；已读后不再重复，未读完可恢复，已有用户正常回访直接进入首页。首次状态按账号记录在本机，不跨设备同步。「还不知道」与明确选择互斥，自述可选。当前主线与其他关注点分开；切换主线不清除原话。匿名流程不依赖后端，不调用模型、不上传自由输入。返回与重新打开可恢复七天内有效草稿，支持主动清除；只有本机写入并读回核对成功后才显示已保存

探索意图、用户实际问题、分支回答、帮助方式与用户命名的标题分别管理。标题可以为空，界面使用明确的未命名探索提示，不能把操作文案伪造成职业目标。新字段通过追加 exploration JSON 迁移保存，不重置旧数据。初步整理是探索起点，不是人格、能力或潜力判断

四种帮助方式随时可切换：Listen 认真倾听、不强制行动；Discover 依据真实线索寻找连接、说明依据；Compare 比较代价和未知、保留用户决定权；Experiment 明确验证问题、可用资源和停止条件。旧 clarify 映射到 discover、act 映射到 experiment，仅作为运行时兼容，不改写旧账号

初步整理明确来自固定问题，不冒充 AI。登录协议默认不勾选；微信登录不额外要求手机号或头像。AI 需要单独同意才能开启。多选用于了解背景，一次只跟进一个当前问题。首页有继续话题、记录想法、探索下一步三个动作，底部为首页、对话、我的。

匿名草稿、账号、生活背景、当前问题、支持方式、确认卡片、聊天、主题与同意记录分别管理。生活背景不自动变为确认事实；支持方式登录后可修改。注册与 AI 同意按版本记录，撤回 AI 同意和删除账号均有真实后端操作。

卡片分为：正在考虑的方向、现实约束、用户确认的信息、尚未证实的可能性、待核实信息、愿意尝试的下一步。尚无方向的用户先探索，不把模型推测包装成职业匹配结论。

模型以用户真实提供的信息为依据，允许提出可解释、待验证的新连接，不自动联网获取岗位、薪资或行业前景，不代用户投递、联系他人或执行行动。AI 建议是草稿，不自动覆盖已确认卡片。

「还有一种可能」是可选的新角度，不是随机职业推荐。需要至少两段不同的用户原话线索，并明确观察、可能性和未验证之处。后端检查引用确实存在，AI 旧回复、卡片推测与系统标签不能作为依据；这不代表推理或职业适配已经得到证明。缺少线索时先询问，不强制出卡

「这个角度有意思」准备可修改的追问，用户再决定是否发送；「不太像我」直接略过，最近三条拒绝只留在当前会话上下文，避免重复推荐相同文案；「让我试一下」打开包含行动、验证目标、投入上限与停止条件的实验草稿，确认后才更新卡片下一步。没有实验时先带入可编辑的询问，不自动请求模型。浏览、拒绝、打开草稿都不产生额外模型调用，不建立任务或永久人格画像

默认只保存问题、确认卡片和反馈，完整聊天由用户选择保留。用户主动打开时接续，无主动提醒。第一版使用微信小程序，Vue 3 + TypeScript + uni-app，Python + FastAPI，Supabase PostgreSQL；H5 只用于本地预览。

登录前统一 Morning Mist：暖白、深色文字、低饱和绿、山湖与自然光影。登录后可切 Quiet Night；晨曦、森林、薰衣草、极简标为计划中。按钮即时反馈，支持减少动效偏好。Insight 使用轻描边与清晰层次，不增加持续发光、随机话术或主动提醒。流畅度、字体设置、键盘和安全区域最终以微信真机验收

总运行预算上限 100 元/月，先分配 20 元作为 AI 应用额度，其他资源费用由实际部署方案确定。该范围不意味着尚未选择的服务器已经包含在费用估算中。
