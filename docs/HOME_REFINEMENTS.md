# Home icons, focus tags and rotating quotations

Date: 2026-10-22

## Scope

The homepage keeps its existing navigation and exploration data. This change corrects native icon alignment, distinguishes the three focus tags, and replaces the fixed quotation with a local editable catalogue.

## Icon alignment

`SvgIcon.vue` previously declared `virtualHost` at the Vue component's top level. The installed uni-app runtime reads native settings from `vueOptions.options`, so that declaration did not remove the WeChat custom-component host. Its inline baseline shifted the inner SVG image downward inside otherwise centered flex containers.

The isolated native regression reproduced a 1.67px vertical offset in all three focus icons and about 2.01px in the mission arrow. The topbar and navigation images were already centered. The component now declares `options: { virtualHost: true }` and its visual root uses flex layout with zero line height. Component style isolation was not disabled.

The native helper measures the actual center of each icon against its frame: three focus icons, one mission arrow, two topbar images and five navigation images. After the correction, all eleven have zero horizontal and vertical center error in both tested themes.

## Tag colors

The labels keep their text as well as their color, so color is not the only way to distinguish them:

- Plan: teal
- Reflection: warm amber
- Conversation: muted purple

Foreground, fill and border tokens are generated by `themeStyle` for all six themes. Tests verify three distinct colors and at least 4.5:1 foreground-to-fill contrast for each label in each theme.

## Quotation catalogue and lifecycle

`apps/miniprogram/src/home-quotes.json` contains twelve original Agency Bloom lines. Each item has a stable `id`, a `text` string with intentional line breaks, and a `source` label. The homepage renders this data rather than embedding one fixed quotation in its template.

`App.vue` registers `refreshHomeQuote` with the app-level `onShow` hook. Cold launch and return from the background select another item, excluding the last displayed id. Only that id is saved under `agency.home.quote.v1`; no private user content, network fetch or model request is involved. Normal tab switches and page remounts reuse the current reactive quotation. Storage failure falls back to in-memory rotation without blocking the application.

The quotation card uses two large, accessibility-hidden curly quotation marks. The former left margin rule and footer dash have been removed. The source label remains separate below the quotation.

## Repeating native checks safely

`tools/verify-home-refinements-native.cjs` only attaches to its isolated tourist project at `output/home-refinements/native-project` on automation port 9449. Its local fixture uses port 8029. Never point this helper at the personal project or reuse personal sessions.

Close only that QA project before rebuilding its directory. Build with `VITE_API_BASE_URL=http://127.0.0.1:8029/api` in a dedicated terminal and pass `--outDir` for this isolated directory. The `--prepare` mode verifies the URL and sets `touristappid`, disabled URL checking and disabled component hot reload. Then open this prepared project with the installed CLI's `auto` command and run the helper. The disposable service is the existing `mock-discovery-api.py` app served on port 8029 instead of its default port. It reads no backend environment file or personal database.
